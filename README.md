## 🇷🇺 Русский

### 🎯 Что умеет AURA

- 💬 **Чат с локальной LLM** - работает без интернета после установки
- 👁 **Распознавание изображений** - пришли фото, AURA расскажет, что на нём
- 🌐 **Поиск в интернете** - RAG с DuckDuckGo и чтением страниц
- 📚 **Долгосрочная память** - учится на диалогах, запоминает факты
- 🌍 **Два языка** - русский и английский (автоопределение)
- 🎨 **Тёмная тема** - приятный интерфейс с подсказками при наведении
- 📌 **Иконка в трее** - работает в фоне

### 🚀 Быстрая установка

#### Способ 1 — автоматический (рекомендуется)

1. **Скачай проект** - кнопка **Code → Download ZIP**, распакуй
2. **Запусти `install.bat`** двойным кликом  
   Установщик сам:
   - Проверит Python
   - Установит библиотеки
   - Проверит и установит Ollama
   - Скачает модели (~5 ГБ, 5–15 минут)
   - Создаст ярлык **AURA** на рабочем столе
3. **Запускай через ярлык AURA** на рабочем столе

pip install -r requirements.txt
